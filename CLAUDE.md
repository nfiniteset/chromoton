# Chromoton

## Working from PLAN.md

This project tracks active work in [PLAN.md](PLAN.md). Treat it as the source of truth for what's in progress and what's next:

- At the start of a session, check PLAN.md to see what's currently in progress before asking the user what to work on.
- When the user describes new work, add it to PLAN.md under the right section rather than only holding it in conversation.
- When a task is started, move it into "In Progress". When it's finished, move it into "Done" with a one-line note of what happened. When it's dropped or superseded, remove it rather than leaving it stale.
- Keep entries terse — this is a working list, not a design doc. Longer rationale belongs in commit messages or code comments, not here.
